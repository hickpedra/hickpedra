### 🚀 Highlighted Projects

#### 🏛️ [API Gov - NFSe Agent (StonesDev)](https://github.com/hickpedra/StonesDev_ContadorDigital)
*An AI-driven assistant designed to manage government API integrations across Brazil.*
*   **Architecture**: Built using the **Model Context Protocol (MCP)** and native SOAP/REST clients in TypeScript.
*   **Integrations**: Fully automated regional SOAP tax services for São Paulo (Paulistana WebServices), Belo Horizonte (ABRASF/BHISS), and Minas Gerais (SEFAZ-MG).
*   **Security**: Encrypted e-CNPJ digital certificate registry using AES-256-GCM.
*   **Federal Data**: Directly queries tax data (Simples Nacional, MEI, DAS) via Integra Contador (SERPRO).

#### 🛒 [HonestMarket Logistics Manager](https://github.com/hickpedra/honestmarket)
*A backend management system for checkout terminals and franchise logistics.*
*   **Operations**: Optimizes planogram management, inventory replenishments, and category analysis.
*   **Features**: Dynamic server-side filtering across categories and locations, and supplier portal integrations to extract prices, compare substitutes, and execute agentic quotes.
*   **Stack**: Python, FastAPI, SQLite, Playwright.
